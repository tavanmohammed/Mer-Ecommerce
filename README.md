

# 🛒 Full-Stack E-Commerce Website

This is a full-stack e-commerce application built with **React**, **Node.js/Express**, and **MongoDB**, designed for managing products and processing real online payments. The system includes a complete admin panel and customer shopping experience.

## ✨ Main Features

### 🔐 Authentication

Secure sign-in and role-based access for admins and customers.

### 🛠️ Admin Product Management

Admins can fully manage the store’s products:

* Add new products
* Edit product details
* Delete products
* Upload images, prices, descriptions, and categories

### 🛍️ Customer Shopping Experience

Customers can browse products, add items to their cart, and place orders through a smooth, responsive interface.

### 💳 Stripe Payment Integration

The website supports real and test payments using **Stripe Checkout**, ensuring secure payment processing.

### 🛒 Cart & Orders

Customers can manage their cart, view totals, and complete secure orders handled by the backend API.

## 🛠️ Tech Stack

* **Frontend:** React + Tailwind
* **Backend:** Express.js
* **Database:** MongoDB
* **Payments:** Stripe
* **Auth:** JWT
